| File | Source | Changes |

| `instrument-sans.woff2` | Instrument Sans, The Instrument Sans Project Authors, via `@fontsource-variable/instrument-sans` 5.3.0 | None: the package's Latin, weight-axis file |
| `newsreader-roman.woff2` | Newsreader, The Newsreader Project Authors, via `@fontsource-variable/newsreader` | Weight pinned to 360; optical size kept at 16–72; subset to Latin-1 and common punctuation |

Instrument Sans stands in for Switzer, the voice of the XI Lab's Odysxi templates. Switzer's licence (ITF FFL) allows self-hosting on your own site but restricts passing the font files on, and this repository is public. Set beside Switzer at the landing's size, Instrument Sans came closest in width and rhythm. Third-party alt text outside the Latin range falls back to the system font.
