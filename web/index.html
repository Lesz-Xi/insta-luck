Rules it keeps

  1. 01Public pages onlyPrivate accounts and removed posts won’t work, and it never asks for your Instagram login.
  2. 02You do the browsingA profile link returns the handful of recent posts Instagram shows publicly, not the whole account. To reach an older post, paste its own link.
  3. 03Results can be incompleteA carousel can come back short. It can’t always tell how many images a post holds, so it never calls a set complete.
  4. 04Images, not videoA Reel link may return a still image. Video isn’t supported.
  5. 05Your link leaves this pageThe post link goes to our server and to Jina Reader, a public page reader. Images pass through our server so their bytes can be checked. We don’t store them or keep a history. A short-lived cookie ties your results to this browser.
  6. 06Save only what you mayUse Insta Luck for images you’re authorized to save.
